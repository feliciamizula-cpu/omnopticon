# Contributing to Argus

Thank you for your interest in contributing to Argus!

## Getting Started

A good starting point is reviewing `docs/ARGUS_IMPLEMENTATION_HANDOFF.md` to understand the project roadmap and current priorities.

## Contribution Principles

- **Bug Bounty Safety**: All contributions must maintain scoped bug-bounty safety boundaries - no unbounded recursive crawling, all HTTP workers must obey rate limits.
- **Incremental Verification**: Build after each meaningful change and verify tests pass.
- **No Regressions**: Do not reintroduce eShop commerce projects or break existing functionality.

## Code of Conduct

To ensure a welcoming and positive environment for everyone, please adhere to our Code of Conduct. Respectful collaboration is key to a successful project.
